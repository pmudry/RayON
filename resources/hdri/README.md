# HDRI Environment Maps

Place `.hdr` (Radiance RGBE) files here to use them as background sky domes in the interactive renderer.

## Keyboard Shortcuts (Interactive Mode)

- **Numpad +** — next HDR environment
- **Numpad −** — previous HDR environment

Index 0 is always the built-in procedural gradient sky (no HDR file required).

## Free CC0 HDRIs from Poly Haven

Download with the script below, or visit https://polyhaven.com/hdris

```bash
# Quick download (2K resolution, ~10–40 MB each)
bash download_hdri.sh
```

| Filename (stem)           | Description                   |
|---------------------------|-------------------------------|
| `venice_sunset`           | Warm orange sunset over water |
| `kloppenheim_06`          | Clear blue midday sky         |
| `autumn_crossing`         | Overcast autumn field         |
| `studio_small_03`         | Neutral studio lighting       |
| `sunflowers_puresky`      | Bright sunny open field       |
| `rosendal_plains_2`       | Open plains, partly cloudy    |
